## 攻略要点

- **游玩时长**：3 天 2 夜（两条主推线：西北园林 / 中东南老街 / 南线运河，不走回头路）
- **Day 1 湖光塔影**：瘦西湖 → 大明寺 → 古运河夜游
- **Day 2 园林老街**：早茶 → 个园 → 东关街 → 皮市街 → 何园 → 泡澡修脚
- **Day 3 运河文明**：中国大运河博物馆 → 仁丰里 / 彩衣街 → 返程

## 已核实的坑点提醒

- **扬州宴**：价格高、出品口碑两极、有食品安全投诉，谨慎。
- **趣园**：口碑最佳但排队极狠（凌晨排队、6:30 放号）。
- **富春**：要点散座、别点套餐（人均 30+ 才划算）。
- **冶春**：去老店（西冶春）才正宗，御码头景区店勿去。
- **郑远元修脚（连锁）**：投诉高发，涉及「治疗 / 办卡 / 承诺根治」坚决拒绝。
- **东关街街口、虹桥坊、瘦西湖正门**：高价溢价区，多走几步价差大。
